# Paper Results Gate

This directory stores paper-facing canonical result CSVs. It is the only intended source for main-table candidates.

Rules:

- OGSOD main-table rows must use `protocol_id=ogsod_hbb_nomosaic_clean_a1b_probea_20260619`.
- LADD main rows must use `method=ladd_probea`, `phase_chain=A1->B`, `ladd_mode=dynamic_probe`, `run_tag` containing `clean_a1b_dynprobe`, and `claim_usable=yes`.
- Historical mosaic100, A1-A2-B, BN-freeze, smoke, partial, close@100, 400ep, and diagnostic runs must be marked unusable for the main table.
- Curated main-table CSVs must pass `tools/paper_validate_main_table.py`.
- Checkpoints, TensorBoard events, W&B directories, datasets, and full raw run directories are not stored here.

Files:

| Path | Purpose |
|---|---|
| `main_table_schema.csv` | Canonical main-table field definition |
| `README_CN.md` | Chinese paper-results gate |
| `example_valid.csv` / `example_invalid.csv` / `validator_fixtures/` | Validator fixtures covering valid mainline rows, legacy rejects, and YAML gate rejects |
| `ogsod_nomosaic/baselines.csv` | Verified SAR/RGB paper baselines |
| `ogsod_nomosaic/ladd_probea.csv` | Verified LADD Probe-A paper rows |
| `ogsod_nomosaic/comparisons.csv` | Verified paper comparison rows |
| `ogsod_nomosaic/ablations.csv` | Static/Dynamic/other ablation rows |
| `ogsod_nomosaic/main_table_candidate.csv` | Combined candidate table generated by collector |
| `vedai/` | Optional cross-dataset validation records |
