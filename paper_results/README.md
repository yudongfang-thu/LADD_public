# Paper Results Gate

This directory stores paper-facing canonical result CSVs. It is the only intended source for main-table candidates.

Rules:

- OGSOD main-table rows must use `protocol_id=ogsod_hbb_mosaic100_ladd_20260619`.
- LADD main rows must use `method=ladd`, `phase_chain=A->B`, `ladd_mode=dynamic_probe`, `run_tag` containing `clean_a1b_dynprobe`, and `claim_usable=yes`.
- No-mosaic rows are fallback/robustness rows unless explicitly moved to an appendix table. Historical A1-A2-B, BN-freeze, smoke, partial, 400ep, and diagnostic runs must be marked unusable for the main table.
- Curated main-table CSVs must pass `tools/paper_validate_main_table.py`.
- Checkpoints, TensorBoard events, W&B directories, datasets, and full raw run directories are not stored here.
- VEDAI / DroneVehicle rows use the separate `cclkd_yolo11n_cross_dataset_20260619` extension protocol and must not be merged into the OGSOD mosaic100 main table.

Files:

| Path | Purpose |
|---|---|
| `main_table_schema.csv` | Canonical main-table field definition |
| `README_CN.md` | Chinese paper-results gate |

| `ogsod_mosaic100/ladd.csv` | Verified LADD paper rows |
| `ogsod_mosaic100/comparisons.csv` | Verified paper comparison rows |
| `ogsod_mosaic100/ablations.csv` | Static/Dynamic/other ablation rows |
| `ogsod_mosaic100/main_table_candidate.csv` | Combined candidate table generated by collector |
| `vedai/` | Optional VEDAI / DroneVehicle cross-dataset validation records aligned to CCLKD YOLO11n |
