# CoLD 方法整理版

这份文档是对原始 `cold.md` 的重构整理版，目标是把被打散的公式、重复表述和不统一的符号恢复成适合阅读与实现的说明。内容重点放在 CoLD 的核心思想、公式定义和代码实现映射。

## 1. 方法概览

CoLD（Category-oriented Localization Distillation）是一种跨模态目标检测蒸馏方法，核心目标是：

- 用光学教师网络提供更强的类别先验与定位信息
- 用 SAR 学生网络学习这些知识
- 推理阶段只保留 SAR 学生网络，不需要光学输入

在 CoLD 中，主要有两个核心模块：

- `CPM`：Category-oriented Partition Module，类别引导的分区/解耦模块
- `IWM`：IoU-based Weighting Module，基于 IoU 的蒸馏加权模块

整体流程如下：

1. 教师网络输入光学图像，输出分类与边界框预测。
2. 学生网络输入 SAR 图像，输出对应预测。
3. CPM 将边界框分布拆成“目标部分”和“非目标部分”。
4. IWM 根据教师框质量对蒸馏项进行加权。
5. 训练时采用在线知识蒸馏；推理时只用学生网络。

## 2. 符号约定

为避免原文符号混乱，先统一记号：

- `T`：教师网络（optical branch）
- `S`：学生网络（SAR branch）
- `B`：边界框相关输出
- `C`：类别预测
- `G`：真实标注（ground truth）
- `t`：当前考虑的目标类别或目标分量索引
- `c`：类别总数
- `i`：检测层索引，YOLOv5 中通常 `i ∈ {1, 2, 3}`
- `α`：解耦后非目标分布损失的权重
- `τ`：Softmax 温度参数

## 3. CPM：边界框分布表示与解耦

### 3.1 为什么要把边界框看成分布

传统回归通常直接预测边界框参数，例如：

- `[x, y, w, h]`
- `[x_min, y_min, x_max, y_max]`

这种写法只给出一个点估计，不表达位置不确定性。CoLD 的思路是把边界框的每个回归量看成一个离散概率分布，再用其期望表示最终坐标。

设某一条边的回归变量为 `y`，其离散取值空间为：

```text
{y_0, y_1, ..., y_n}
```

则预测值写成：

```math
\hat{y} = \sum_{i=0}^{n} p(y_i)\, y_i
```

其中：

- `p(y_i)` 是该位置的概率
- 概率分布通常由一个 `n+1` 维 Softmax 输出得到

如果写成连续形式，则可以理解为：

```math
\hat{y} = \int_{y_0}^{y_n} x\, p(x)\, dx
```

离散实现更适合代码。

### 3.2 目标/非目标分布解耦

设某个预测的完整概率分布为：

```math
p = [p(y_0), p(y_1), \ldots, p(y_t), \ldots, p(y_n)]
```

其中 `t` 表示当前关注的目标位置或目标类别对应的分量。CoLD 将其拆成两部分：

1. 目标概率

```math
p_t = p(y_t)
```

2. 非目标总概率

```math
p_{\setminus t} = \sum_{i \ne t} p(y_i) = 1 - p_t
```

然后，对非目标部分重新归一化，得到非目标条件分布：

```math
\hat{p}_i = \frac{p(y_i)}{\sum_{j \ne t} p(y_j)} = \frac{p(y_i)}{p_{\setminus t}}, \quad i \ne t
```

于是，一个原始分布被拆成：

- 二值目标分布 `b = [p_t, p_{\setminus t}]`
- 非目标条件分布 `\hat{p}`

这个拆分是 CoLD 的核心，因为它将“目标置信”和“其余竞争项的相对分布”分开处理。

## 4. 解耦蒸馏损失

### 4.1 传统 KD

传统知识蒸馏直接最小化教师与学生完整分布的 KL 散度：

```math
\mathrm{KD} = \mathrm{KL}(p^T \parallel p^S)
```

展开后就是：

```math
\mathrm{KD}
= p_t^T \log \frac{p_t^T}{p_t^S}
+ \sum_{i \ne t} p_i^T \log \frac{p_i^T}{p_i^S}
```

这种写法的问题是：目标项和非目标项耦合在一起，目标概率越大，非目标部分受到的影响越强。

### 4.2 解耦后的形式

利用

```math
p_i = \hat{p}_i \, p_{\setminus t}, \quad i \ne t
```

可以把 KL 分解成两项：

```math
\mathrm{KD}
= \mathrm{KL}(b^T \parallel b^S)
+ (1 - p_t^T)\, \mathrm{KL}(\hat{p}^T \parallel \hat{p}^S)
```

其中：

- `KL(b^T || b^S)` 衡量目标概率的一致性
- `KL(\hat{p}^T || \hat{p}^S)` 衡量非目标分布的一致性

原文将这两部分分别命名为：

- `TPD`：Target Probability Distribution
- `NPD`：Non-target Probability Distribution

### 4.3 CoLD 的解耦 KD 损失

CoLD 认为上式中的系数 `(1 - p_t^T)` 仍然会让两部分存在耦合，因此用超参数 `α` 替换它：

```math
L_{kd}
= \sum_{t=0}^{N}
\left[
\mathrm{KL}(b_t^T \parallel b_t^S)
+ \alpha \, \mathrm{KL}(\hat{p}_t^T \parallel \hat{p}_t^S)
\right]
```

这里：

- 第一项保留目标信息蒸馏
- 第二项对非目标分布进行独立蒸馏
- `α` 控制非目标项强度

原文给出的经验值是：

```text
α = 2
```

## 5. 类别引导分区

### 5.1 为什么还要做类别分区

如果对每个位置或回归分量都做一次上述解耦，计算量会很大。原文提到当候选数较大时，这种做法会带来明显开销。

因此 CoLD 进一步引入“类别引导的分区”：

- 先用教师分类分支输出类别预测
- 再将预测转为 one-hot 硬标签
- 用该类别标签去引导回归分支分组
- 最后只在类别级别上做解耦蒸馏

### 5.2 类别级公式

记：

- `m_t`：属于第 `t` 类的所有概率分布集合
- `\hat{m}_t`：移除第 `t` 类后的其他概率分布集合

则类别级蒸馏写成：

```math
L_{kd}
= \mathrm{KL}(m^T \parallel m^S)
= \sum_{t=0}^{c}
\left[
\mathrm{KL}(m_t^T \parallel m_t^S)
+ \alpha \, \mathrm{KL}(\hat{m}_t^T \parallel \hat{m}_t^S)
\right]
```

其中 `c` 为类别数。

### 5.3 温度参数

类别分布通常会通过带温度的 Softmax 获得：

```math
\mathrm{Softmax}(z / \tau)
```

当 `τ > 1` 时，分布会更平滑，通常能提供更丰富的暗知识。原文经验设置为：

```text
τ = 20
```

## 6. IWM：基于 IoU 的蒸馏加权

### 6.1 动机

跨模态检测里，教师网络虽然更强，但它的候选框也不一定都高质量。如果对所有候选框一视同仁地蒸馏，低质量框会把错误定位信息传给学生。

IWM 的目标是：

- 给高质量教师框更大权重
- 抑制低质量教师框对蒸馏的负面影响

### 6.2 各层 IoU 权重

对教师网络每个检测层 `i`，计算其预测框与真实框的匹配 IoU：

```math
a_i = \mathrm{IoU}(B_i^T, B^G), \quad i \in \{1,2,3\}
```

其中：

- `B_i^T`：教师网络第 `i` 个检测层输出的候选框
- `B^G`：对应真实框
- `a_i`：第 `i` 层蒸馏权重

### 6.3 加权后的蒸馏损失

最终在三个检测层上加权求和：

```math
L_{kd}^{\mathrm{IWM}}
= \sum_{i=1}^{3} a_i \, L_{kd}(B_i^T \parallel B_i^S)
```

其中 `B_i^S` 是学生网络在第 `i` 层的候选框输出。

这意味着：

- 教师框与真值越接近，对学生的监督越强
- 教师框质量越差，其蒸馏贡献越小

## 7. 整体训练目标

CoLD 使用在线蒸馏（OKD），教师和学生同时训练。

### 7.1 教师损失

教师网络只优化自身检测目标：

```math
L_T(\Theta_1)
= L_{cls}(C^T, C^G) + L_{reg}(B^T, B^G)
```

其中：

- `\Theta_1`：教师参数
- `C^T`：教师分类输出
- `C^G`：真实类别标签
- `B^T`：教师回归输出
- `B^G`：真实框

### 7.2 学生损失

学生网络除了检测损失，还要加蒸馏损失：

```math
L_S(\Theta_2)
= L_{cls}(C^S, C^G)
+ L_{reg}(B^S, B^G)
+ L_{kd}^{\mathrm{IWM}}
```

其中：

- `\Theta_2`：学生参数
- `C^S`：学生分类输出
- `B^S`：学生回归输出

原文提到回归损失使用 `CIoU`，因为它会更关注中心位置偏差。

## 8. 代码实现映射

如果要在 YOLOv5 上实现 CoLD，可以按下面的模块拆：

### 8.1 双分支网络

- 教师分支输入 optical 图像
- 学生分支输入 SAR 图像
- 两支网络结构可同构，但参数独立

### 8.2 CPM 模块

需要做四件事：

1. 将边界框回归输出转换成离散概率分布
2. 根据教师分类结果生成类别引导分区
3. 构造 `b_t` 与 `\hat{p}_t`
4. 计算 TPD + `α *` NPD 的解耦蒸馏损失

### 8.3 IWM 模块

需要做三件事：

1. 计算每个检测层教师框与真值框的匹配 IoU
2. 将 IoU 作为层级或样本级权重
3. 对蒸馏损失做加权汇总

### 8.4 训练策略

- 训练时教师和学生同时前向
- 教师只回传检测损失
- 学生回传检测损失和蒸馏损失
- 推理阶段丢弃教师分支，只保留 SAR 学生分支

## 9. 一页版总结

CoLD 可以压缩成一句话：

> 先用教师的类别先验把定位分布拆成“目标部分”和“非目标部分”，再用 IoU 对高质量教师框赋予更大蒸馏权重，从而更稳健地把光学模态的定位知识迁移到 SAR 学生网络。

最关键的三个公式是：

```math
\hat{y} = \sum_{i=0}^{n} p(y_i)\, y_i
```

```math
\mathrm{KD}
= \mathrm{KL}(b^T \parallel b^S)
+ (1 - p_t^T)\, \mathrm{KL}(\hat{p}^T \parallel \hat{p}^S)
```

```math
L_{kd}^{\mathrm{IWM}}
= \sum_{i=1}^{3} a_i \, L_{kd}(B_i^T \parallel B_i^S)
```

经验超参数：

- `τ = 20`
- `α = 2`

推理约束：

- 只使用学生网络
- 输入仅为 SAR 图像
- 不需要光学图像
