# 实验 registry 说明（2026-06-14）

本目录是本地实验证据的统一索引层。它不替代人工结论，但可以回答：

- 某个 run 在本地有没有证据？
- 它来自哪台服务器？
- 是否有重复副本？
- best/last AP 是多少？
- 是否有 `args.yaml`、`ladd_diagnostics.csv`、manifest？

## 文件

| 文件 | 作用 |
|---|---|
| `experiment_registry_20260614.csv` | 全仓 `results.csv` 扫描索引 |
| `duplicate_results_20260614.csv` | 按 `results.csv` hash 识别重复副本 |
| `experiment_registry_summary_20260614.json` | 数量统计 |
| `protocol_summary_20260614.csv` | 按工作线、训练协议、schedule、用途聚合的数量表 |
| `local_large_artifacts_20260614.csv` | 本地大文件/权重备份位置说明，不用于 GitHub |

## 重要字段

| 字段 | 含义 |
|---|---|
| `family` | 自动推断的实验族：`ladd`、`comparison`、`baseline`、`cclkd_*` |
| `method` | 自动推断的方法名 |
| `source_server` | 自动推断来源：`ladd90`、`ladd4090`、`autodl`、`server117` 等 |
| `validity` | 自动粗标：`candidate_or_unknown`、`diagnostic`、`invalid_or_diagnostic` |
| `experiment_line` | 三条线归属：`cclkd_reproduction`、`comparison_methods`、`ladd_mainline_diagnosis` 等 |
| `protocol_id` | 训练协议粗分：`formal_nomosaic_800`、`formal_nomosaic_compressed`、`cclkd_paper_mosaic400`、`historical_mosaic_mainline`、`smoke_probe_partial`、`unknown_protocol` |
| `mosaic` | 从 `args.yaml` 或路径推断的 mosaic 值 |
| `epochs_planned` | 从 `args.yaml` 或 run name 推断的计划 epoch |
| `schedule_class` | `full_800`、`compressed`、`paper_400`、`smoke_probe_partial`、`unknown` |
| `role` | 自动粗分用途：`mainline_candidate`、`diagnostic`、`comparison`、`baseline`、`archive_or_invalid` 等 |
| `claim_usable` | 粗略可用性：`yes`、`partial`、`no`；仍需人工复核 |
| `results_hash` | `results.csv` 内容 hash，用于去重 |
| `canonical_path` | 当前副本路径，不等于最终论文 canonical |
| `best_ap` / `last_ap` | 从 `results.csv` 直接解析的 best/last |

## 使用注意

1. `validity=candidate_or_unknown` 只是脚本粗判，不代表可进入论文主表。
2. 如果一个 hash 有多个副本，先查 `duplicate_results_20260614.csv`，不要重复计数。
3. `smoke`、`diag`、`probe`、`snapshot`、`old` 等 run 默认只能用于诊断。
4. LADD 主线结论必须再经过人工标注：`role`、`protocol_matched`、`claim_usable`。
5. 新同步服务器数据后，应重新运行 registry 脚本，并更新 [DATA_ORGANIZATION_PLAN_20260614_CN.md](../DATA_ORGANIZATION_PLAN_20260614_CN.md) 中的统计。
6. 本地权重和压缩包位置见 `local_large_artifacts_20260614.csv`；这些文件只用于本机复盘或恢复，不进入 GitHub。
